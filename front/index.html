Quelques bases du shell

Cette présentation a pour but de vous faire découvrir les bases du shell. N'hésitez pas à cliquer sur les commandes en rouge pour les exécuter, ou à les taper dans le terminal.

Le shell et les processus

La ligne de commande que vous avez ici permet de lancer d'autres programmes. Vous pouvez les visualiser en tapant 
  • ps
Vous pouvez remarquer que deux processus sont présents: bash et ps.
Si vous ajoutez l'option -f, la commande va donner la liste des processus avec plus d'informations. 
  • ps -f
Le principe est que le shell dans lequel vous avez tapez la commande se met en sommeil pour laisser le ps s'exécuter
Vous pouvez essayer vous même en faisant l'un après l'autre: 
  • bash
  • ps -f
  • exit
  • ps -f
Saurez vous interpréter le résultat que vous venez d'obtenir ?
